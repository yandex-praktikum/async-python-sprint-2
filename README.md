# Проектное задание второго спринта

Ваша задача — написать планировщик задач для обработки поступающих тасков.

## Описание задания

**1. Описать реализацию класса `Scheduler`.**

Условия и требования:
- планировщик реализован на основе очереди, по умолчанию ее размер равен 50;
- планировщик умеет добавлять задачу в очередь и запускать ее в рамках настроек, указанных в таске;


**2. Описать реализацию класса `Task`.**

Условия и требования:
- у задачи может быть указано время его запуска (опциональный параметр).
Если этот параметр указан, то задача стартует в указанный временный период.

- у задачи может быть указана длительность ее выполнения.
Если этот параметр указан, то задача самоуничтожается, если время выполнения превысило указанный параметр.
- у задачи может быть указаны зависимости - задача или задачи, от которых завист ее выполнение.
Если этот параметр указан, то задача не может стартовать до момента, пока не будут завершены задачи-зависимости.
- у задачи может быть указан параметр количества рестартов, если в ходе выполнения произощел сбой или задачи-зависимости не были решены.
Если этот параметр не указан, то количество рестартов равно 0.

**3. Проверить работу планировщика на различных задачах**

Условия и требования:
- работа с файлами;
- работа с сетью;
- работа с файловой системой;


## Требования к решению

1. Используйте концепции ООП.
2. Описать реализации классов
3. Используйте аннотацию типов.
4. Для хранения статус задачи или очереди планировщика использовать `.lock`-файлы или иные текстовые форматы -`txt`, `json`
5. Предусмотрите обработку исключительных ситуаций.
6. Приведите стиль кода в соответствие pep8, flake8, mypy.

## Рекомендации к решению

1. Логируйте результаты действий.
2. Покройте написанный код тестами.
